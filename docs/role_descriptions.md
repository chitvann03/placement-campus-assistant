# Engineering Campus Placement Role Descriptions

Guide to entry-level profiles in Indian campus recruitment, covering duties, skills, career paths, and salary benchmarks for RAG indexing.

---
## 1. Software Development Engineer (SDE)

- **What the Role Does**: Designs, builds, tests, and deploys scalable software applications, backend services, and user interfaces solving business needs.
- **Day-to-Day Responsibilities**:
  - Writing clean, maintainable code in Java, C++, Python, or Go.
  - Participating in agile ceremonies and peer code reviews.
  - Designing REST APIs, database schemas, and data pipelines.
  - Debugging production defects and maintaining automated unit tests.
- **Required Skills**:
  - *Technical*: Data Structures & Algorithms (DSA), OOP, DBMS/SQL, OS concepts, Git, REST APIs.
  - *Soft*: Analytical thinking, structured problem-solving, and team collaboration.
- **Typical Companies**: Google, Microsoft, Amazon, Adobe, Oracle, Goldman Sachs, Flipkart.
- **Career Path**: SDE-1 -> SDE-2 -> Senior SDE -> Principal Engineer / Engineering Manager.
- **Salary Range (India)**:
  - Product / Super Dream: ₹15 LPA – ₹45+ LPA CTC
  - IT Products / Mid-Tier: ₹7 LPA – ₹14 LPA CTC

---

## 2. Data Analyst

- **What the Role Does**: Inspects, cleans, and models structured data to uncover business trends and produce visual intelligence for strategic decision-making.
- **Day-to-Day Responsibilities**:
  - Writing SQL queries to transform data from relational databases and warehouses.
  - Building interactive dashboards and executive reports in Power BI or Tableau.
  - Performing exploratory data analysis and statistical testing with Python (pandas).
  - Tracking product metrics and evaluating A/B experiment outcomes.
- **Required Skills**:
  - *Technical*: Advanced SQL, Python (pandas, numpy), Excel/VBA, Power BI/Tableau, applied statistics.
  - *Soft*: Commercial awareness, data storytelling, and stakeholder communication.
- **Typical Companies**: Mu Sigma, Fractal Analytics, EXL Service, Tiger Analytics, Deloitte, Amazon.
- **Career Path**: Junior Analyst -> Senior Data Analyst -> Analytics Lead / Manager -> Director of Analytics.
- **Salary Range (India)**:
  - Analytics Specialists & Tier-1: ₹8 LPA – ₹16 LPA CTC
  - IT Services & Consulting: ₹4.5 LPA – ₹8 LPA CTC

---

## 3. Business / Management Consultant

- **What the Role Does**: Diagnoses operational, financial, and organizational challenges for corporate clients and designs actionable strategic growth and cost-optimization solutions.
- **Day-to-Day Responsibilities**:
  - Conducting market research, industry benchmarking, and financial data analysis.
  - Mapping business workflows and identifying operational bottlenecks.
  - Building financial valuation models and cost-benefit spreadsheets in Excel.
  - Creating persuasive slide decks and presenting recommendations to client executives.
- **Required Skills**:
  - *Technical*: Advanced MS Excel, financial modeling, PowerPoint storyboarding, basic SQL.
  - *Soft*: Hypothesis-driven problem-solving, executive presentation, and adaptability.
- **Typical Companies**: McKinsey & Company, BCG, Bain, Deloitte, PwC, EY, KPMG, ZS Associates.
- **Career Path**: Associate Consultant -> Consultant -> Senior Consultant -> Engagement Manager -> Partner.
- **Salary Range (India)**:
  - Strategy Consulting (MBB): ₹14 LPA – ₹24 LPA CTC
  - Big Four & Boutique Consultancies: ₹6 LPA – ₹12 LPA CTC

---

## 4. Quality Assurance Engineer (QA/SDET)

- **What the Role Does**: Validates software functionality, reliability, and performance by authoring test plans, identifying defects, and engineering automated testing suites.
- **Day-to-Day Responsibilities**:
  - Analyzing product requirements to design functional and edge-case test matrices.
  - Developing and maintaining automated UI and API test scripts using Selenium or Playwright.
  - Executing regression, load testing (JMeter), and API validation in Postman.
  - Logging defects in Jira, collaborating with developers, and verifying bug fixes.
- **Required Skills**:
  - *Technical*: Core Java or Python, Selenium/Playwright, Postman, CI/CD pipelines, SQL, Git.
  - *Soft*: Attention to detail, critical thinking, methodical troubleshooting.
- **Typical Companies**: Amazon, Amdocs, Cognizant, Wipro, Capgemini, Cisco, Qualcomm.
- **Career Path**: QA Trainee -> QA/SDET-1 -> Senior SDET -> QA Lead / Test Architect -> Head of Quality.
- **Salary Range (India)**:
  - Product Companies (SDET): ₹10 LPA – ₹24 LPA CTC
  - IT Services & Consulting: ₹3.8 LPA – ₹7.5 LPA CTC

---

## 5. Systems Engineer

- **What the Role Does**: Provisions, configures, and maintains server infrastructure, operating systems, and network services to guarantee enterprise system reliability and uptime.
- **Day-to-Day Responsibilities**:
  - Administering Linux and Windows servers across on-premises and cloud environments.
  - Monitoring server health, CPU/memory usage, and investigating service outage alerts.
  - Automating administrative routines using shell scripts (Bash, PowerShell, or Python).
  - Executing system patching, security hardening, and backup recovery.
- **Required Skills**:
  - *Technical*: Linux/Unix administration, networking fundamentals (TCP/IP, DNS), Bash/Python scripting, basic cloud.
  - *Soft*: Incident response under pressure, procedural rigor, customer support focus.
- **Typical Companies**: Infosys, TCS, Wipro, HCL Technologies, IBM, Tech Mahindra, LTIMindtree.
- **Career Path**: Systems Engineer -> Senior Systems Engineer -> Infrastructure Lead / Cloud Engineer -> Enterprise System Architect.
- **Salary Range (India)**:
  - Mass IT Service Recruiters: ₹3.6 LPA – ₹4.5 LPA CTC
  - Digital / Specialized Engineering: ₹6.5 LPA – ₹10 LPA CTC
